# Embedded SameBoy boot ROMs

`embedded_boot_roms.c` contains hexadecimal encodings of SameBoy's open boot
ROMs. They were extracted without modification from the verified prebuilt
artifacts committed on SameBoy's `libretro` branch at commit
`8230189896a8bb6598574d302ba0ad3658f98ab4`:

- `BootROMs/prebuilt/dmg_boot.bin`: 256 bytes, SHA-256
  `6f64da4cecd7e54e2f928eb3e3ba7810a7a567d0d247cc71737d1771e073a916`
- `BootROMs/prebuilt/cgb_boot.bin`: 2304 bytes, SHA-256
  `f767b8e7e510a255f81328c89dba6e0c996b370e1bc86aebb8584a7da47a5bba`

The corresponding assembly sources are `BootROMs/dmg_boot.asm` and
`BootROMs/cgb_boot.asm` in the pinned SameBoy engine source at commit
`213a12ce93d66b105a113debd9396306066a7cfc`. The current assembly tree is
identical to the one used for the verified prebuilt artifacts.

is Copyright (c) 2015-2026 Lior Halphon and distributed under the Expat
License. The notice is reproduced in `SAMEBOY_LICENSE.txt`; its authoritative
source is the `LICENSE` file at the root of the pinned SameBoy checkout. These
bytes must not be replaced with Nintendo's proprietary boot ROM dumps.

To reproduce the bytes from source, install a pinned RGBDS toolchain supported
by SameBoy, run SameBoy's `make bootroms`, and compare the two SHA-256 hashes
above before updating the hexadecimal encodings.
